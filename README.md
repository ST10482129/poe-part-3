# Khula Community Bakery Website

# 1. Project Overview

Khula Community Bakery is a website developed for a fictional community bakery based in Benoni, Gauteng, South Africa.

The purpose of the website is to provide customers with information about the bakery, display available products, allow customers to make enquiries and provide contact information.

The website aims to make it easier for customers to explore bakery products and communicate with the business online.

## 2. Project Objectives

The main objectives of this website are to:

- Create an attractive and user-friendly bakery website.
- Display bakery products and services.
- Allow customers to submit product enquiries.
- Provide contact information and a location map.
- Improve communication between the bakery and customers.
- Make the website accessible on desktop and mobile devices.

## 3. Technologies Used

The following technologies were used to develop the website:

- **HTML5:** Used to structure the website content.
- **CSS3:** Used to style the pages and create a responsive layout.
- **JavaScript:** Used to add functionality and interactivity.
- **Google Maps:** Used to display the bakery's location.
- **GitHub:** Used for source code management and version control.

## 4. Website Pages

The website contains the following pages:

| Page | Description |
|---|---|
| Home | Introduces Khula Community Bakery and its products. |
| About Us | Provides information about the bakery and its background. |
| Products | Displays the bakery's available products. |

## 5. Website Features

The website includes the following features:

- Responsive navigation menu.
- Bakery product gallery.
- Lightbox feature that allows users to view enlarged product images.
- Product information and descriptions.
- Customer enquiry form.
- Contact information.
- Google Maps location map.
- Responsive design for different screen sizes.

## 8. Search Engine Optimisation (SEO)

Search Engine Optimisation (SEO) is used to improve the visibility of the Khula Community Bakery website on search engines such as Google.

The website uses the following SEO practices:

### 8.1 On-Page SEO

- **Page titles:** Each webpage has a descriptive title to identify its content.
- **Meta descriptions:** Meta descriptions provide search engines with a short summary of each webpage.
- **Keywords:** Relevant keywords such as "Khula Community Bakery", "bakery in Benoni", "fresh bread" and "bakery products" help describe the website's content.
- **Heading structure:** HTML heading elements are used to organise webpage content.
- **Image optimisation:** Images should have descriptive file names and meaningful alternative text (alt text).
- **Internal linking:** Navigation links connect the different pages of the website.
- **Mobile-friendly design:** Responsive CSS helps the website display on different screen sizes.

### 8.2 Technical SEO

The following technical SEO files and practices are included in the project:

- **robots.txt:** Provides instructions to search engine crawlers about which areas of the website they may access.
- **sitemap.xml:** Provides search engines with information about the website's pages.
- **Clean HTML structure:** Semantic HTML elements help organise website content.
- **Responsive design:** Supports a better browsing experience on mobile devices, tablets and computers.

### 8.3 Local SEO

The website includes business location and contact information for Benoni, Gauteng. Google Maps is also included on the Contact page to help visitors identify the bakery's location.

### 8.4 Benefits of SEO

SEO can help the bakery to:

- Improve its visibility in search engine results.
- Reach customers searching for bakery products in Benoni.
- Increase website visits.
- Help customers find important business information.
- Improve the overall user experience.
